## ⚡ О проекте

**Folders** — это быстрое нативное десктопное приложение для системных администраторов Windows, созданное командой **Crazy Monkeys**. Оно позволяет в едином современном **Cyber Emerald Glass** интерфейсе подключаться к файловым серверам домена Active Directory, просматривать активные сетевые папки (SMB Shares), управлять правами доступа к шарам и правами безопасности NTFS, а также контролировать открытые сессии и заблокированные файлы.

---

## 🔥 Основные возможности

### 🖥 1. Управление серверами и интеграция с Active Directory
- **Пул постоянных сессий WinRM (`PSSession`)**: мгновенное переключение между серверами без повторного ожидания инициализации PowerShell.
- **Автоматический импорт серверов из AD («🔍 Из AD»)**: находит все компьютеры под управлением *Windows Server* в текущем домене Active Directory и позволяет добавить их в пару кликов.
- **Прозрачная доменная авторизация**: работает от имени вашей текущей доменной учетной записи (Kerberos / Integrated Windows Auth), а для локального компьютера выполняет команды напрямую без накладных расходов WinRM.

### 📁 2. Управление сетевыми шарами (SMB Shares)
- Просмотр всех активных шар сервера с фильтрацией по имени, пути на диске и описанию.
- Переключатель скрытия/отображения административных и системных шар (`C$`, `ADMIN$`, `IPC$`).
- Бейджи состояния: `Системная`, `Скрытая ($)`, `ABE Вкл` (*Access-Based Enumeration*), счетчик активных подключений.
- Быстрые действия в один клик: **Копирование UNC-пути** (`\\server\share`) и **Открытие шары в Проводнике Windows**.

### 💽 3. Визуальный проводник дисков удаленного сервера
- Просмотр всех физических и логических дисков удаленного сервера с отображением свободного и общего места в ГБ.
- Навигация по дереву каталогов удаленного сервера в реальном времени.
- **Создание новых папок прямо на удаленном сервере** из окна обзора при создании шары.

### 🔐 4. Двойной контроль прав: SMB Permissions + NTFS Security (ACL)
- **Права общего доступа (SMB)**: выдача и отзыв прав `Чтение (Read)`, `Изменение (Change)`, `Полный доступ (Full)` и `Запретить (Deny)` + быстрые пресеты (`Все`, `Администраторы`).
- **Права безопасности папки (NTFS ACL)**:
  - Просмотр полного списка правил безопасности и текущего владельца папки.
  - Управление наследованием прав (`Включить / Отключить наследование` с сохранением текущих унаследованных правил).
  - Добавление и удаление явных правил NTFS с выбором области применения (`Эта папка, подпапки и файлы`, `Только эта папка`, `Только подпапки и файлы` и др.).
- **Умный поиск пользователей и групп («🔍 Найти в AD / Сервере»)**: ищет учетные записи и группы одновременно в домене **Active Directory** (`[adsisearcher]`), локальной базе целевого сервера и среди встроенных системных SID.

### 👥 5. Мониторинг активных сессий и открытых файлов
- **Активные сессии (`Get-SmbSession`)**: просмотр подключенных пользователей, IP/имени клиента, времени сессии, простоя и принудительный сброс сессии (`Close-SmbSession`).
- **Открытые файлы (`Get-SmbOpenFile`)**: быстрый поиск того, кто держит файл открытым или заблокированным на сервере, с кнопкой принудительного закрытия файла (`Close-SmbOpenFile`).

### 🎨 6. Кастомизация и темы оформления
- Мгновенная смена темы оформления без перезапуска приложения:
  - 🟢 **Cyber Emerald** — фирменный зелено-черный Glass-стиль от *Crazy Monkeys*
  - ⚡ **Neon Matrix** — контрастный матричный неон на глубоком черном
  - 🌿 **Obsidian Mint** — спокойный мятный графит
  - 💠 **Cyber Blue** — кибер-синий лед
- Управление эффектами матового стекла (`Glassmorphism`), фоновым автообновлением, таймаутами WinRM и параметрами шар по умолчанию.

## 🚀 Установка и запуск

### Вариант 1: Готовый релиз (Рекомендуется)
1. Перейдите в раздел **[Releases](../../releases)**.
2. Скачайте:
   - **`Folders-v2.0.0-win-x64-SingleFile.exe`** — полностью автономный `.exe` (не требует установки .NET Runtime), **или**
   - **`Folders-v2.0.0-Portable.zip`** — компактная портативная сборка.
3. Запустите `Folders.exe` (для управления локальными шарами рекомендуется запуск от имени Администратора).

### Вариант 2: Сборка из исходного кода
```powershell
git clone https://github.com/ficksj/Folders.git
cd Folders
dotnet run -c Release
```

## 🛠 Требования к окружению
- **ОС**: Windows 10 / Windows 11 / Windows Server 2016–2025.
- **Удаленные серверы**: включенный стандартный сервис **WinRM / PowerShell Remoting** (`Enable-PSRemoting -Force` — на Windows Server включен по умолчанию) и права локального администратора на целевом файловом сервере.
